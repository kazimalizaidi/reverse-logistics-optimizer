# Olist data goes here

The raw Olist CSV files are not stored in this repository (size and licence: CC BY-NC-SA 4.0).

1. Download the dataset: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Copy these files into this folder:
   - `olist_orders_dataset.csv`
   - `olist_order_items_dataset.csv`
   - `olist_order_reviews_dataset.csv`
   - `olist_customers_dataset.csv`
   - `olist_products_dataset.csv`
   - `olist_sellers_dataset.csv`
   - `olist_geolocation_dataset.csv`
   - `product_category_name_translation.csv`
3. Run `python run_pipeline.py` from the project root.

Dataset credit: Olist, "Brazilian E-Commerce Public Dataset by Olist" (Kaggle).
